ce-net / Demos / Read before you act

Read it before you can act.

Alice sends Bob a change notice and a key to approve the change. The key says: only after a signed read receipt for this notice. Press approve before reading and the page shows the exact clause that refuses it. Open the notice, Bob's phone signs a receipt, and the same approve goes through.

This copy is static, so it shows the recorded run (proof/transcript.json). To press the buttons yourself, run it locally: git clone https://github.com/ce-net/demo-demo-read-before-act && cd demo-demo-read-before-act && cargo run -p demo-read-before-act -- up and open http://127.0.0.1:7400/.
